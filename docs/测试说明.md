## 5. 测试数据说明

- 自动化测试使用内存 SQLite（TestConfig）与临时目录，不污染开发数据库。
- 端到端脚本会新建“E2E 验证果园”等记录；建议对独立实例运行（见 README 的环境变量方式）。
- 开发库中的演示数据由 scripts/seed_demo.py 写入，图片为程序合成图，识别为 OpenCV 演示模式，均带“演示”标记。

## 6. 未覆盖 / 已知问题

1. 没有真实陈皮柑模型，因此没有 Precision/Recall/mAP 等模型指标可测。
2. 未做并发/压力测试；识别是同步的，批量上传大量图片会长时间占用请求。
3. 未做跨浏览器兼容性矩阵，只在 Chrome/Edge 验证。
4. 未实现自动化 UI 测试（如 Selenium/Playwright），页面交互为手工验收。
