# 智能助手说明（数据库事实 + 本地大模型）

> 状态：**已接入本机 Ollama（默认 qwen3:8b）**，2026-10-23 实测可用。没有配置模型时自动退回规则问答。

## 1. 为什么不是“直接把问题丢给大模型”

果园问答涉及数量、日期、名称，模型自己编一个数字看起来也很像真的。所以这里采用**检索增强（RAG）**思路：

```text
用户问题
  → 后端按意图查数据库（未完成任务 / 识别统计 / 估产 / 异常 / 概况）
  → 没命中意图时生成一段总体上下文（果园、地块、计划、影像、最近估产、类别统计）
  → 把【数据库事实】+【问题】交给模型，要求“只能依据事实回答”
  → 返回 answer（模型组织语言）+ facts（事实原文，页面可展开核对）
```

页面同时展示「AI 回答」和「查看数据库依据」，答辩时可以现场点开对照，证明数字不是模型编的。

## 2. 架构

| 层 | 文件 | 作用 |
|---|---|---|
| 路由 | `app/routes/assistant.py` | 意图识别、事实检索、调用模型、失败降级 |
| 服务 | `app/services/llm.py` | Ollama / OpenAI 兼容接口、状态检测、超时与异常 |
| 页面 | `app/templates/assistant.html` | 对话、状态徽标、依据折叠、冷却提示 |
| 配置 | `app/config.py` + `.env` | provider、base_url、model、key、timeout |

## 3. 配置

### 3.1 本机 Ollama（默认，免密钥）

```text
LLM_ENABLED=1
LLM_PROVIDER=ollama
LLM_BASE_URL=http://127.0.0.1:11434
LLM_MODEL=qwen3:8b
LLM_TIMEOUT=120
```

前提：本机安装并启动 Ollama，且执行过 `ollama pull qwen3:8b`。可用 `ollama list` 查看已有模型。

### 3.2 云端 OpenAI 兼容接口（DeepSeek / 通义 / Moonshot 等）

```text
LLM_PROVIDER=openai
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
LLM_API_KEY=你的密钥
```

密钥只放 `.env`（已在 `.gitignore` 中），不要写进代码或前端。

### 3.3 病虫害知识问答（文本）

助手内置一份柑橘常见病虫害知识库（黄龙病、溃疡病、炭疽病、疮痂病、红蜘蛛、潜叶蛾、裙腐病）：
用户问“溃疡病怎么办”“红蜘蛛怎么防治”时，先检索知识库，再由模型组织成可读建议，并附
“仅供辅助参考，实际诊断需现场或农技人员确认”的免责声明。

> 注意：这是**文本知识问答**，不是图像病害识别。要“看照片判断病害”，需要带标注框的病害数据集
训练独立模型；目前没有稳定可用的公开数据。

## 4. 提示词约束

```text
你是“陈皮柑果园智慧管理系统”的业务助手。
你只能依据用户消息中给出的【数据库事实】回答，不能编造任何数量、名称、日期或结论。
如果事实里没有相关信息，就直接说“当前数据库里没有这项数据”，并给出可以查询的方向。
回答用简洁中文，必要时用短列表；不要输出 Markdown 表格。
```

## 5. 可靠性与体验

- **状态徽标**：页面顶部显示“本地 AI · qwen3:8b”或“规则问答（模型未就绪）”；
- **预热**：打开助手页时后台调用 `/assistant/warm`，把模型加载好，首次提问不至于等几十秒；
- **超时与降级**：模型超时/报错时返回 `answer=null` + `error`，页面展示“AI 暂不可用”并给出规则查询结果；
- **不写库**：问答不产生业务数据，纯读取。

## 6. 测试覆盖

- `test_assistant_db_answers`：规则问答仍可用（未命中/命中意图）；
- `test_assistant_uses_llm_when_ready`：模型可用时返回 answer，source=ai；
- `test_assistant_falls_back_when_llm_fails`：模型异常时降级并保留 facts 与 error；
- 空问题返回 400。

## 7. 已知限制

1. **7B 本地模型**能力有限，复杂推理/多轮追问容易答偏，适合“查数+解释”这类任务；
2. **无多轮记忆**：每次提问独立，不保留上下文（避免把旧数据当新数据）；
3. **非流式输出**：等待期间只有“思考中”动画，没有逐字输出；
4. **事实范围有限**：只覆盖规则意图 + 总体上下文，问“某棵树第几片叶子”这类问题会回答“没有这项数据”；
5. 冷启动首次加载模型约 40 秒（已预热后约 0.5–1 秒）。

## 8. 后续可扩展
