# 系统设计（与当前代码一致）

## 1. 架构

```
浏览器（Jinja2 页面 + Chart.js）
   │ HTTP
Flask 蓝图（app/routes）── 参数校验(utils) ── 业务服务(app/services)
   │                                      ├ storage     上传校验/安全存储/路径防穿越
   │                                      ├ detector    YOLO 加载缓存/推理/OpenCV 演示/结果图绘制
   │                                      ├ recognition 识别执行与入库
   │                                      ├ stats       汇总/驾驶舱/图表
   │                                      ├ yield_service 估产公式与样本汇总
   │                                      ├ reports     报表构建、Excel/PDF 输出
   │                                      └ llm         数据库事实 → 本机 Ollama / OpenAI 兼容接口
SQLAlchemy ORM ── SQLite（instance/orchard.db）    文件 ── storage/{originals,results,reports}
```

## 2. 数据库表

| 表 | 说明 | 关键字段 |
|---|---|---|
| orchards | 果园 | code 唯一、name、region、area_mu、variety、planting_date、density、expected_trees、is_demo |
| plots | 地块 | orchard_id→orchards、code（果园内唯一）、area_mu、tree_count、variety、latitude/longitude（预留） |
| inspection_plans | 巡检计划/批次 | orchard_id、plot_id（空=全园）、planned_date、executed_date、owner、method、status |
| images | 巡检影像 | plan_id、original_name、stored_path 唯一、file_size、width/height、captured_at(EXIF)、sample_trees、source（采集方式）、status、archived、is_abnormal、GPS（EXIF/手填） |
| recognition_runs | 一次识别 | image_id、mode(yolo/opencv_demo)、model_name、conf_threshold、device、status、error_message、total_count、class_counts、size_counts、result_path、duration_ms、reviewed_count/review_note/reviewed_at（人工复核，不覆盖模型结果） |
| detections | 检测框 | run_id、class_id、class_name、confidence、x1..y2、area_ratio、size_grade、maturity（颜色估算） |
| yield_estimates | 估产记录 | level、orchard_id、plot_id、plan_id、count_source、样本果数/树数、株均果、目标树数、校正系数、单果重、预计果数、预计产量、class_breakdown、formula、remark、is_demo |
| harvest_records | 实际采收记录 | orchard_id、plot_id、year、actual_yield_kg、avg_price、note、is_demo |
| reports | 导出报表归档 | report_type、fmt、title、file_path、params |
| users | 系统用户 | username 唯一、password_hash（PBKDF2-SHA256）、role、is_active、must_change_password、last_login_at |

删除规则：果园有地块/计划/估产时不能删除；地块有计划/估产时不能删除；计划有影像/估产时不能删除（可以改为“已取消”）；已归档的影像不能删除；删除影像时会级联删除它的识别记录和文件。

## 3. 关键业务规则

- **任务进度** = 批次中“已识别”的影像数 ÷ 影像总数，按实际记录实时计算。
- **识别**：每次识别（包括重新识别）都会新增一条 run，历史记录保留；统计时每张图取最新一次成功的 run。失败也会记录原因。
- **人工复核**：只写入 reviewed_* 字段，模型原始结果不变；统计页面同时显示“模型原始数”和“复核后数”。
- **成熟度**：按检测框内橙黄色/绿色像素比例估算青/转色/成熟，写入 detections.maturity 与 run.maturity_counts；页面、报表标注“颜色估算，非模型分类”。
- **覆盖**：地块覆盖率 = 已有影像的计划数 ÷ 该地块计划总数；识别率 = 已识别影像 ÷ 影像数。
- **采收对比**：估产偏差 =（全园估产合计 − 实际采收合计）÷ 实际采收合计；实际采收按年登记。
- **估产**：样本平均可见果数 = 样本果数 ÷ 样本树数；预计总果数 = 平均可见果数 × 目标树数 × 校正系数；预计产量 = 总果数 × 单果重(g) ÷ 1000。样本树数来自每张影像填写的覆盖树数。目标树数：单株 = 1，地块 = 地块株数，全园 = 果园预计株数（为空时取各地块株数之和）。
- **同比/环比**：按“全园”估产记录按月汇总（同一果园同月只取最新一条），环比对比上一个自然月，同比对比去年同月；缺少相邻月份或去年同月数据时页面显示“数据不足”，不做任何推断。

## 4. 主要路由

| 路径 | 方法 | 功能 |
|---|---|---|
| `/` | GET | 对外首页（公开，Apple 风格落地页） |
| `/dashboard` | GET | 数据驾驶舱 |
| `/live/`、`/live/detect` | GET/POST(JSON) | 实时识别页面与逐帧推理接口（不落库） |
| `/api/charts`、`/api/model-status` | GET | 图表数据、模型状态（JSON） |
| `/orchards/`、`/new`、`/<id>`、`/<id>/edit`、`/<id>/delete` | GET/POST | 果园增删改查 |
| `/plots/...` | GET/POST | 地块增删改查 |
| `/plans/...`、`/plans/<id>/status` | GET/POST | 巡检计划、状态更新 |
| `/images/`、`/images/upload` | GET/POST | 影像查询、多文件上传（可勾选自动识别） |
| `/images/<id>`、`/images/file/<id>/<original\|result>` | GET | 影像详情、安全输出图片 |
| `/images/<id>/detections.json` | GET | 某次识别的检测框（供前端动画） |
| `/images/<id>/recognize`、`/images/plan/<id>/recognize` | POST | 单张/批量识别（auto/yolo/opencv_demo） |
| `/images/<id>/update`、`/toggle/<archived\|is_abnormal>`、`/delete` | POST | 信息维护、归档、异常标记、删除 |
| `/results/`、`/results/run/<id>/review` | GET/POST | 结果筛选汇总、人工复核 |
| `/yields/`、`/yields/new`、`/yields/samples/<plan_id>`、`/yields/<id>` | GET/POST | 估产列表、新建、样本汇总 JSON、详情 |
| `/harvest/`、`/harvest/new`、`/harvest/<id>/delete` | GET/POST | 实际采收记录增删与年度对比 |
| `/reports/`、`/reports/export`、`/reports/download/<id>` | GET/POST | 报表预览、导出 Excel/PDF、下载归档 |
| `/assistant/`、`/assistant/ask`、`/assistant/warm` | GET/POST(JSON) | 业务助手（数据库事实 + 本地大模型，含预热） |
| `/login`、`/logout`、`/account/password` | GET/POST | 登录、退出、修改密码（未登录访问其他页面会跳转到登录页，接口返回 401） |
| `/database/`、`/database/export` | GET | 只读数据浏览（表名白名单 + 仅 SELECT）、CSV 导出 |

## 5. 安全措施

上传只接受 jpg/jpeg/png 扩展名，并用 Pillow 校验实际内容和格式；单张大小有上限（默认 15MB）；文件名由 uuid 生成，以独占模式写入，不会覆盖已有文件；读取文件时只使用数据库中的相对路径，并检查是否位于 storage 目录内；所有表单字段都在服务端校验；密钥通过环境变量配置。

登录与会话：密码用 PBKDF2-SHA256 哈希存储，数据库中不保存明文；会话只保存用户 id，每次请求重新加载用户，账号被禁用后立即失效；Cookie 为 HttpOnly + SameSite=Lax，会话默认 8 小时过期；登录失败 5 次后本会话内锁定；登录后跳转地址只接受站内相对路径，防止开放重定向；初始管理员首次登录会被强制引导到修改密码页。
